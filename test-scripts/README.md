# Test Scripts

Sample scripts for testing Script Toolbox features.

## Scripts

| File | What it tests |
|---|---|
| `hello.sh` | Basic instant output |
| `countdown.sh` | Live streaming output (sleep loop) |
| `stderr_demo.sh` | Mixed stdout/stderr and non-zero exit |
| `sys_info.sh` | Real system info via shell commands |
| `hello.py` | Basic Python output |
| `fibonacci.py` | Python streaming output with a loop |

## How to import

In Script Toolbox, click **+ Folder** in the sidebar and select this `test-scripts/` directory.
All scripts will be imported and this README will be displayed.
